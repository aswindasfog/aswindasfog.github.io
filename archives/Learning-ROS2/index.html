學習 ROS 2

發表於2026-11-07|更新於2026-11-07|ROS
|總字數:1.2k|閱讀時間:3分鐘

緣起

我一直對於軟硬體整合的領域很有興趣，常常關注相關的科技新聞，之前第一次看到波士頓動力的機器狗影片時，真的令人驚豔，隨著科技發展，晶片的效能跟AI的能力越來越強，可以看到越來越多相關技術商業化，像是倉儲系統的無人車、開上路的自駕車等等，現在連人形機器人也越來越像樣了。

雖然我想學習相關技術，但研究了嵌入式系統的相關資訊，發現從 Arduino 、 Raspberry Pi 到 NVIDIA Jetson 運算效能雖然越來越強，但硬體價格也越來越高，所以一直沒有下定決心要學習，直到最近工作接觸到了 Robot Operating System 2（ROS2），發現這個軟體架構已經做好硬體抽象化，讓開發者可以輕鬆地進行模擬測試，也讓新人可以透過模擬的方式學習，因此我就決定來學習 ROS2 了。

前期研究

ROS 2 是一套開源的軟體、函式庫與工具，可協助建立機器人應用程式，官方網站就有免費提供完整的文件跟教學，完全不需要苦惱怎麼學。

接下來就是考慮如何實際安裝練習，我考量了以下幾點：

  • ROS 2 有支援 Ubuntu 、 Windows 以及 MacOS 等作業系統，但 Ubuntu 支援度最好。

  • 目前常見的開源機器人大多使用了 Raspberry Pi 或 NVIDIA Jetson ，並安裝了 Ubuntu 來執行程式。

  • 後續想用 3D 的模擬軟體來學習，為了避免效能問題，所以選擇實體機器，而非虛擬機器。

而我手邊剛好有一台舊電腦可以重灌來用，所以就決定用舊電腦安裝 Ubuntu 跟 ROS 2。

再來是版本相容性問題，ROS 2 的版本釋出方式跟維護期限是採用類似 Ubuntu 的作法，官方文件就有告知適合的配對組合，所以我選擇了稍微舊一點，但還沒停止維護的 ROS 2 Humble Hawksbill ，以及與它搭配 Ubuntu 22.04 。

學習 ROS 2

安裝過程依照官方安裝說明就可以順利安裝，這裡就不再贅述。

接著就是依照官方教學文件開始學習，官方提供一個範例程式 turtlesim 進行教學，基本上就是一個簡單的視窗，模擬一個 2D 的世界，然後裡面可以產生許多個 2D 海龜，並操作移動這些海龜，藉此學習 ROS 2 的基本概念，以及官方工具如何使用。

簡單來說，ROS 2 採用模組化的架構，一個 node 應該只負責一個功能，node 之間透過 ROS 2 的標準化通訊方式傳遞訊息，最後藉由多個 node 推疊出完整的機器人系統，舉例來說：一個無人車可能會有 node 只負責把感測器的資訊送出，有 node 只負責依照命令去驅動輪子。

ROS 2 的通訊方式是採用 Data Distribution Service （DDS），這是一種即時通訊中介軟體標準，它是分散式架構，所以不會有單點故障風險，支援動態自動探索，可隨時加入或離開通訊網路，並且有 QoS 策略可以依使用情境調整可靠度，簡而言之，它讓開發機器人應用功能的工程師可以節省處理通訊功能的時間。

了解基本概念後，接著學習 ROS 2 的建置工具以及函式庫，官方提供 C++ 跟 Python 函式庫，兩種都有提供教學讓你寫出 ROS 2 node，由於使用標準化通訊的關係，所以 C++ 寫出的 node 可以跟 Python 寫出的 node 互相通訊，因此可以依照實際需求，混用兩種程式語言建立機器人系統，而當你的系統有越來越多的 node 時，一個一個執行就太沒效率了，所以 ROS 2 有一個 launch 系統，讓使用者以更有效率與彈性的方式啟動整個機器人系統。

學到這邊，我感覺已經對 ROS 2 有足夠的了解，可以試著寫出在機器人上執行的 ROS 2 程式了，而且後續的官方教程大多是講函式庫比較細節的部份，於是我決定先跳到了模擬的部分。

小結

不知不覺就打了破千個字，所以先來個小結，模擬的部分改天再繼續寫，雖然 ROS 2 學到這邊還沒真的自行建立機器人系統，但可以感覺到它的優點是結構良好、方便擴充，確實適合機器人系統，缺點的部分目前覺得建置方式比想像中複雜，感覺只能邊做邊學了，期待後續的學習。
